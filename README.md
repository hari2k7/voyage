# Voyage

Voyage is a modern desktop travel planner application built using Electron.js, HTML, CSS, and JavaScript.  
It helps users organize trips, manage budgets, plan itineraries, track packing lists, and explore destinations through a clean and interactive interface.

---

## Features

- Splash Screen
- Trip Planning Dashboard
- Places Explorer
- Budget Management
- Itinerary Planner
- Packing Checklist
- Settings Page
- Desktop Application using Electron
- Clean Modular Project Structure

---

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Electron.js

## Installation

Clone the repository:

`git clone https://github.com/hari2k7/voyage.git`

Move into the project directory:

`cd voyage`

Install dependencies:

`npm install`

Run the application:

`npm start`

Build Desktop Application

To generate an executable desktop app:

`npm run dist`

The generated setup file will appear inside the dist/ folder.
